# Linux Commands I Learned - Day 1

## pwd (Print Working Directory)
- **What it does:** Shows your current location in the file system
- **Why use it:** Know where you are before running commands

## ls (List)
- **What it does:** Shows files and folders in current directory
- **Flags:** `ls` = simple, `ls -la` = detailed

## mkdir (Make Directory)
- **What it does:** Creates a new folder
- **Example:** `mkdir devops-practice`

## touch
- **What it does:** Creates an empty file
- **Example:** `touch my-file.txt`

## echo
- **What it does:** Prints text or writes to file
- **Example:** `echo "Hello DevOps" > my-file.txt`

## cat
- **What it does:** Shows file content
- **Example:** `cat my-file.txt`

## cp (Copy)
- **What it does:** Copies a file
- **Example:** `cp file.txt file-copy.txt`

## rm (Remove)
- **What it does:** Deletes a file
- **Warning:** Cannot undo!

## find
- **What it does:** Searches for files
- **Example:** `find . -name "*.txt"`

## chmod
- **What it does:** Changes file permissions
- **Example:** `chmod 755 my-file.txt`
